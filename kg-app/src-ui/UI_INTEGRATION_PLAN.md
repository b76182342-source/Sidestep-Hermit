# UI 集成计划

## 分模块开发策略

为了确保每个模块功能正常，我们将按以下顺序进行：

### Phase 1: 基础样式系统 (独立测试)
- [ ] 提取全局样式和主题变量
- [ ] 创建 `styles/globals.css`
- [ ] 创建 `styles/theme.css`
- [ ] 测试：创建简单的样式预览页面

### Phase 2: 核心组件重构 (逐个测试)
- [ ] **侧边栏导航** (`Sidebar.tsx`)
  - 测试：独立渲染，检查导航交互
- [ ] **播放器控制栏** (`Player.tsx`)
  - 测试：独立渲染，检查播放控制
- [ ] **搜索组件** (`Search.tsx`)
  - 测试：独立渲染，检查搜索输入
- [ ] **歌曲列表** (`TrackList.tsx`)
  - 测试：独立渲染，检查列表显示

### Phase 3: 高级功能组件 (逐个测试)
- [ ] **正在播放页面** (新建 `NowPlaying.tsx`)
  - 测试：独立渲染，检查歌词显示
- [ ] **专辑详情页** (新建 `AlbumDetail.tsx`)
  - 测试：独立渲染，检查专辑信息
- [ ] **艺术家页面** (新建 `ArtistPage.tsx`)
  - 测试：独立渲染，检查艺术家信息
- [ ] **歌单详情** (新建 `PlaylistDetail.tsx`)
  - 测试：独立渲染，检查歌单显示
- [ ] **设置页面** (新建 `Settings.tsx`)
  - 测试：独立渲染，检查设置项

### Phase 4: 路由和布局集成
- [ ] 设置路由系统（可选：React Router 或简单状态管理）
- [ ] 集成所有页面组件
- [ ] 测试：页面间导航

### Phase 5: 功能集成
- [ ] 连接 Tauri 后端 API
- [ ] 状态管理集成
- [ ] 测试：端到端功能

## 测试方法

### 组件独立测试
每个组件都会创建一个独立的测试页面：
```bash
npm run dev:component <ComponentName>
```

### 样式预览
```bash
npm run dev:styles
```

### 完整应用测试
```bash
npm run dev
```
