# KGPlayer 安装指南

## 快速安装

### Ubuntu/Debian 用户（推荐）

```bash
sudo dpkg -i KGPlayer_0.1.0_amd64.deb
sudo apt-get install -f
```

### 所有 Linux 发行版（AppImage）

```bash
chmod +x KGPlayer_0.1.0_amd64.AppImage
./KGPlayer_0.1.0_amd64.AppImage
```

## 系统要求

- Linux x86_64
- GStreamer 1.0
- 512 MB RAM
- 100 MB 存储空间

## 首次使用

1. 启动 KGPlayer
2. 点击"扫描音乐库"
3. 开始播放音乐

详细说明请查看 `M5-RELEASE.md`
